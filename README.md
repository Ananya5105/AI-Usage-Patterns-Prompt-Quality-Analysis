# AI Usage Patterns & Prompt Quality Analysis

End-to-end analytics pipeline analyzing 100K+ conversational AI interaction records across 4 datasets.

## Stack
Python · Pandas · Scikit-learn · PostgreSQL · Power BI

## Datasets
- LMSYS Chatbot Arena
- OpenAssistant (OASST1)
- ChatGPT Prompts Dataset
- Student AI Usage Survey

## Pipeline
Raw Data → Python/Pandas (cleaning & EDA) → PostgreSQL (star schema) → Power BI (6 dashboards)

## Dashboards
1. Executive Overview
2. User Behavior Analytics
3. Prompt Analytics
4. AI Dependency Dashboard
5. Student AI Usage Analytics
6. Recommendations Dashboard
